SRS — RepoLens AI

Software Requirements Specification

Project: RepoLens AI
Version: 1.0.0
Date: 17/09/2026
Target: MVP
Development Approach: AI-Driven Development / Spec-Driven Development
Team size: 5 members
Primary stack: .NET 10 + Next.js + PostgreSQL

1. Giới thiệu
1.1. Mục đích

RepoLens AI là hệ thống hỗ trợ người dùng hiểu một repository/project phần mềm mà họ chưa quen thuộc bằng cách kết hợp:

Source code analysis
Static analysis
Dependency analysis
Architecture analysis
API analysis
Database analysis
Knowledge model
Retrieval-Augmented Generation (RAG)
AI-generated explanation
Evidence/traceability

Người dùng cung cấp:

Git repository URL, hoặc
Project ZIP file.

Hệ thống sẽ đọc và phân tích source code, xây dựng thông tin cấu trúc của repository và cung cấp giao diện trực quan kết hợp AI Chat để giải thích project.

2. Vấn đề cần giải quyết

Khi tiếp cận một project lớn hoặc project của người khác, developer mới thường phải mất nhiều thời gian để tìm hiểu:

Project có những module nào?
Entry point nằm ở đâu?
Các project phụ thuộc nhau như thế nào?
API endpoint nằm ở đâu?
Class/service nào gọi class/service nào?
Database entity/table nào tồn tại?
Một chức năng đi qua những file nào?
Một file/class có vai trò gì?
Kiến trúc tổng thể của project là gì?

RepoLens AI nhằm giảm thời gian tìm hiểu bằng cách tự động phân tích repository và giải thích dựa trên bằng chứng thực tế từ source code.

3. Mục tiêu sản phẩm
3.1. Mục tiêu chính

RepoLens AI MVP phải cho phép người dùng:

Xem API endpoints.

AI không được coi là nguồn sự thật duy nhất.

Static analysis và repository evidence là cơ sở để xác định thông tin thực tế.

30. Non-Functional Requirements
NFR-001 — Security

Repository phải được xử lý như untrusted input.

Không được:

Execute arbitrary repository code.
Execute scripts từ repository.
Load malicious binaries.
Expose secrets cho AI.
NFR-002 — ZIP Security

ZIP extraction phải chống:

Path traversal.
Zip bombs.
Excessive file count.
Excessive file size.
NFR-003 — Secret Protection

Các file như:

.env
*.pem
*.key
secrets.*
credentials.*

và các credential/config nhạy cảm phải được loại khỏi AI indexing khi phát hiện.

31. NFR-004 — Repository Isolation

Analysis của repository A không được làm lộ dữ liệu cho repository B.

Knowledge/RAG phải có:

AnalysisId / RepositoryId

làm boundary.
